Патч Initiative Tracker — переключение справки СР по нажатию

В этом патче изменён один файл:
  src/components/InitiativeHeader.tsx

Установка: извлеките архив в корень проекта initiative-tracker с заменой файла,
после чего выполните npm install (если зависимости ещё не установлены) и npm run build.
Опубликуйте обновлённую сборку на своём хостинге.

Изменение:
- Значок «?» открывает и закрывает справку только по нажатию (клик/тап).
- Наведение мыши больше не открывает панель и уход курсора её не закрывает.
- Анимация раскрытия 240 мс, размер окна, полный текст и оба режима счётчика сохранены.
