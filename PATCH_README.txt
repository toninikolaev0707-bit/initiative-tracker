Патч Initiative Tracker: справка по СР (1.6.2)

Замените в своём проекте четыре файла из этого архива, сохраняя пути.
После замены в каталоге проекта выполните:
    npm install
    npm run build
Загрузите содержимое dist на ваш хостинг (например, Cloudflare Pages).

Функции:
- Значок ? возле кнопок меню счётчика.
- Подсказка появляется при наведении мыши, на телефоне — по нажатию.
- Раскрытие с анимацией и автоматическое изменение размеров окна Owlbear Rodeo.
- Весь предоставленный текст сохранён полностью.
- Содержание может прокручиваться на небольших экранах.
- Работает в обоих режимах счётчика.
