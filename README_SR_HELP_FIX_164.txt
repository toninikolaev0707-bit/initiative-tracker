SIGMA СР COUNT PRO 1.6.4 — исправление памятки СР

Причина: версия 1.6.3 помещала памятку за x=250px в том же action iframe.
Если Owlbear не выполнял setWidth(770), CSS width становился 0px, и '?' выглядел нерабочим.

Исправление:
- Отдельный OBR.popover.open для памятки (?srHelp=1), независимо от ширины action.
- '?' открывает памятку при наведении на ПК, а при клике закрепляет её открытой.
- Повторный клик закрывает закреплённую памятку, есть кнопка X.
- Плавное проявление и переносы строк; нет горизонтальной прокрутки.
- Счётчик сохраняет исходную ширину 250px; режимы, СР и синхронизация без изменений.

Для установки патча: распаковать архив в корень проекта (папка initiative-tracker),
заменив файлы. Затем npm install (если зависимости не установлены), npm run build.
Обновить развернутые файлы на Cloudflare Pages и перезагрузить расширение.
